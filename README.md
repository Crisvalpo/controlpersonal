# 👷 Control Personal

App web estática (HTML + JS + CSS, sin build) para control de horas hombre (HH) y reportes de personal por cuadrilla.

## Características
- Reporte de HH agrupado por categoría dentro de cada cuadrilla (squad).
- Cálculo robusto de HH con detección difusa de claves y validación de valores.
- Lectura de datos JSON alojados en Google Drive a través de proxy CORS.

## Uso
Abrir `index.html` en el navegador (o servir la carpeta con cualquier servidor estático). No requiere dependencias ni instalación.

## Archivos
- `index.html` — estructura y vistas
- `script.js` — lógica de carga de datos, cálculo de HH y render de tablas
- `style.css` — estilos

Repo: `Crisvalpo/controlpersonal`. No está desplegado en lukeserver.
